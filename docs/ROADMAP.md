# Contactor Roadmap

This roadmap separates committed near-term direction from expansion ideas. It is not permission for an AI agent to implement an item without a specific task.

## Now — finish the sellable V1

- Complete current AI receptionist / Booking Flow stabilization.
- Reconcile onboarding with the five current tenant-facing Booking Flow choices.
- Simplify onboarding using KISS principles.
- Complete launch-readiness tenant authorization/security review.
- Verify the full customer journey end-to-end.
- Make tenant website brand colors actually drive the public site.
- Resolve launch-critical marketing/auth/email/billing/deployment issues.

## Near launch / high-value follow-on

- Add actual AI assistance to onboarding.
- Add multiple images per Project Gallery project.
- Pass clicked-project context into the AI receptionist.
- Add Google Maps to Service Area/public website/footer where appropriate.
- Implement real reviews data/import/display rather than placeholders.
- Support tenant URLs as `tenant.getcontactor.com`.

## Expansion

- Google Business Profile integration.
- Google Business Profile implementation Chalk Talk / support documentation.
- Admin AI assistant across tenant admin screens for:
  - how-to help
  - configuration suggestions
  - recommendations
  - support/troubleshooting
- Richer review synchronization and management.
- Deeper AI-assisted tenant website configuration.
- Future semantic/embedding RAG improvements after launch needs justify them.

## Parking lot

Keep additional ideas here until explicitly promoted. Brainstormed items should not silently become architecture requirements.
